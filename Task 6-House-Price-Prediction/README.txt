# Task 6: House Price Prediction (Regression)

### 🎯 Objective
Predicting real estate prices based on features like location, number of rooms, and square footage.

### 📊 Dataset
- **House Price Prediction Dataset:** (Custom CSV/Kaggle dataset).

### 🛠 Methodology
- **Preprocessing:** Handled missing values, encoded categorical locations, and applied **StandardScaler** for feature normalization.
- **Models Applied:** Gradient Boosting Regressor & Linear Regression.
- **Metrics:** Evaluated using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).

### 📈 Key Findings
- **Feature Importance:** Number of rooms and location were the highest predictors of price.
- **Visualization:** Scatter plots of Actual vs. Predicted prices showed a strong linear correlation with a low error margin.
