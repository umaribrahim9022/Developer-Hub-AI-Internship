# Task 1: Iris Flower Classification & Visualization

### 🎯 Objective
The goal of this task is to classify Iris flowers into three species (Setosa, Versicolor, and Virginica) based on their petal and sepal measurements.

### 📊 Dataset
Used the classic **Iris Dataset** containing 150 samples with 4 features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### 🛠 Models Applied
- **Exploratory Data Analysis (EDA):** Used Seaborn for pair plots and correlation heatmaps.
- **Model:** Logistic Regression or Random Forest (depending on your final choice).

### 📈 Key Results
- Achieved **X% Accuracy** (usually 95-100%).
- Successfully visualized how Petal length is the strongest feature for classification.
